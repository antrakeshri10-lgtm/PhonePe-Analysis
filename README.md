# PhonePe Transactions Analytics Dashboard
An interactive **Power BI dashboard** built to analyse PhonePe's transaction data and explore transaction trends, user behaviour, service performance and payment patterns.

This project was created as part of my learning journey in **Power BI and data analytics**, with the goal of moving from learning individual tools to applying them in a complete business-focused project.

## 🎯 Project Objective

The objective of this project was to explore transaction data and build an interactive dashboard that can answer questions such as:

- How are transactions changing over time?
- Which services contribute the most transaction value?
- How do different age groups contribute to transactions?
- How does usage differ between weekdays and weekends?
- What is the overall payment success rate?
- Which users have the highest transaction value?

## 🛠️ Tools & Technologies

- **Power BI** — Dashboard development and data visualisation
- **Power Query** — Data cleaning and transformation
- **DAX** — Measures, KPIs and dynamic calculations
- **Excel** — Data handling and preparation

## 📊 Dashboard Features

- **Interactive KPI Cards** for total transactions, transaction value, unique users and success rate
- **Transaction Trend Analysis** to track monthly transaction volume and value
- **Service-wise Analysis** to compare transaction value across different services
- **Customer Segmentation** based on age groups and contribution
- **User-level Analysis** highlighting the top 5 users by transaction value
- **Dynamic Text Insights** that update based on selected filters
- **Interactive Filters & Custom Tooltips** for deeper and more detailed exploration

## 💡 Key Insights

- Weekdays account for a larger share of transaction activity than weekends.
- Loans contribute the highest transaction value among the services analysed.
- Different age segments contribute significantly to overall transaction activity.
- The dashboard records an overall payment success rate of approximately 96%.
- Transaction activity varies across months, with noticeable fluctuations throughout the year.
